The API

Three requests to a live call.

v2 is a small REST surface. One bearer key, JSON in, JSON out, signed webhooks back. Nothing to install, nothing to host.

Base URL
api.voice.miraiminds.co
Auth

Resources
/v2/agents · /v2/calls · /v2/wallet
Events
call.started · call.completed · call.failed · call.voicemail

curl -X POST https://api.voice.miraiminds.co/v2/agents \
  -H "Authorization: Bearer $MIRAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "order-confirmation", "language": "hi-IN", ... }'

What you get

The unglamorous parts, already solved.

Hindi that isn't translated

Hindi and Hinglish are the default, not a locale flag. Indian names, addresses and digit strings come out the way a person would say them.

Sub-second turn-taking

Speech recognition, the model and the voice all run on our own GPUs inside India. No trans-Pacific hop between the caller and the reply.

Voicemail, handled

The agent recognises an answering machine and does what you told it to: hang up quietly, or leave the message you wrote.

Calls that end cleanly

Agents know when a conversation is finished and hang up — instead of trailing off into silence while the meter runs.

Signed, retried webhooks

HMAC-SHA256 with a timestamp and a five-minute replay window. Retries at 1s, 10s, 60s, 5m and 30m before anything is dropped.

Prepaid wallet, over the API

Balance and ledger are just endpoints. A call that would overdraw the wallet returns 402 before the phone ever rings.
